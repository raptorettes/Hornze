# Changelog

All notable changes to Magic Sparkles are documented here.

## 1.0.0 — First public release

- **MagicSparkleLight** — lightweight `_draw()` sparkles for buttons, labels, and icons (1–150 particles)
- **MagicSparkleBatch** — MultiMesh batched sparkles for dense and fullscreen effects (50–5000 particles)
- **MagicSparkleCursor** — mouse and touch magic dust trail with click/tap burst
- **7 motion presets** — Classic, Drift, Rise, Swirl, Orbit, Pulse, Rain with Inspector tuning
- **Activation modes** — On Hover and Always Active
- **Boundary modes** — Clip+Wrap and Fade Exit
- **Signal API** — `activated`, `deactivated`, `hover_entered`, `hover_exited`, `burst_triggered`, `enabled_changed`
- **Cursor presets** — `MagicSparkleCursorPresets` (SUBTLE, AMBIENT, RAINBOW_BURST)
- **6 example scenes** + full documentation (Quick Start, API, Recipes, FAQ, Troubleshooting)
- **Inspector tooltips** on every exported property and enum value
